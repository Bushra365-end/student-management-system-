# Student Management System Using 8086 Assembly Language
 Project Overview
The Student Management System is a simple menu-driven application developed using 8086 Assembly Language in the EMU8086 environment. The project is designed to manage student and course information through a command-line interface.

 Features

 1. Student Management Panel
- Add new student information.
- Display all student records.
- Update existing student information.
- Delete student records using Student ID.
- Search for students using Student ID.
- Store student Name, ID, and CGPA.

 2. Course Management Panel
- Add new course information.
- Display all course records.
- Update existing course information.
- Delete course records using Course Code.
- Search for courses using Course Code.
- Store Course Name, Course Code, and Credit.

 3. Main Menu
- Student Panel
- Course Panel
- Exit

 Technologies Used
- Programming Language: 8086 Assembly Language
- IDE/Simulator: EMU8086
- Platform: DOS-based environment

 Project Objectives
- To understand the fundamentals of 8086 Assembly Language.
- To practice memory management and data storage.
- To implement basic CRUD (Create, Read, Update, Delete) operations.
- To develop menu-driven programming logic.
- To gain practical experience with assembly language instructions.

 How to Run
1. Open EMU8086.
2. Load the `.asm` source code file.
3. Compile and emulate the program.
4. Use the menu options to manage student and course records.

 Conclusion
This project demonstrates the practical implementation of a Student Management System using 8086 Assembly Language. It provides basic student and course management functionalities and helps develop a better understanding of low-level programming concepts.
